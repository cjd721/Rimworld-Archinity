# Archite gene pool

Every gene with `biostatArc > 0` in the **active** mod set - i.e. the exact pool the altar's lottery can draw from.

Sorted by **complexity** (highest first), then metabolic cost. Archite genes are priced almost entirely in complexity - biostatMet is 0 for nearly all of them, so cpx is the only usable power proxy.

Generated by `tools/survey_archite.py`. Regenerate after any mod change.
