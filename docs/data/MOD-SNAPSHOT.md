# Mod snapshot — the corpus on disk

Generated by `python tools/corpus.py --write`. **Do not hand-edit.**

This is the corpus capability research searches, and a **version pin**:
a finding cited against a mod is cited against the version recorded here.
Run `python tools/corpus.py --check` to see what has moved since.

`Act` — in `config/ModsConfig.xml`. **An inactive mod is invisible to
`defdb.py`, `patch_check.py`, `audit_research.py` and `inventory.py`,**
and the active split carries no weight for research (`PARTS-BIN.md`).
`1.6` — loads under 1.6, by About.xml, a version folder or loadFolders.
`Src` — **the game version the shipped C# source is for**, never a bare
yes. A version that is not 1.6 is marked **⚠ stale**: that source does
not describe the assembly the game loads, so decompile the 1.6 dll instead
(`ilspycmd`). VFE Empire ships 176 .cs under `1.4/Source/` and a distinct
dll for each of 1.4/1.5/1.6 — reading its source is reading 1.4.
`Dll` — the version folders shipping an assembly.
